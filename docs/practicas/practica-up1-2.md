# Práctica 2: Agenda de contactos en CSV

⬅️ *Pertenece a la unidad* [UP1 · Bloque 2. Persistencia en ficheros CSV](../up1/bloque-2.md)

Se desea crear una agenda de contactos que los almacene en un fichero de datos incremental. El formato en el que almacenará los datos es **CSV**. Como delimitador se usará `;`.

## Datos a almacenar

La información que deseamos almacenar de cada contacto es la siguiente:

- Nombre
- Apellidos
- Email
- Telefono1
- Telefono2
- Direccion

## Acciones de la agenda

A continuación se definen las acciones que tiene que permitir realizar esta agenda:

1. Iniciar la agenda. Mostrar un menú para usar la agenda.
2. Guardar datos de un contacto.
3. Modificar datos de un contacto.
4. Dar de baja a un contacto (Eliminar).
5. Buscar un contacto.
6. Mostrar la lista de contactos ordenada.
7. Salir de la agenda (Cerrar).
