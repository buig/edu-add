# Acceso a Datos

Bienvenido/a al material del módulo **Acceso a Datos**, perteneciente al **Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**.

En este módulo aprenderás a **leer, escribir y persistir información** desde tus aplicaciones, trabajando tanto con **ficheros** como con **bases de datos relacionales**, y utilizando dos lenguajes y paradigmas distintos: **Python (POO)** y **Java (Spring Boot)**.

## 🎯 Objetivos generales

A lo largo del módulo, el alumnado será capaz de:

- Comprender los distintos mecanismos de persistencia de datos (ficheros, bases de datos).
- Leer y escribir ficheros de texto, binarios, CSV, JSON y XML.
- Diseñar clases orientadas a objetos para encapsular el acceso a los datos.
- Conectar aplicaciones con bases de datos relacionales y ejecutar operaciones CRUD.
- Gestionar transacciones, procedimientos y funciones almacenadas.
- Aplicar criterios de seguridad y buenas prácticas en el acceso a los datos.
- Trasladar estos conceptos tanto a Python como a Java (Spring Boot).

## 📦 Unidades didácticas

A continuación se muestra la estructura general del módulo. Cada unidad cuenta con su propio material, ejemplos y prácticas.

> *(La estructura puede adaptarse según el ritmo del grupo)*

### 🔹 UP1 · Acceso a ficheros

Lectura y escritura de ficheros de texto y binarios en Python: modos de apertura, la sentencia `with`, ficheros de log, persistencia en CSV/JSON/pickle y trabajo con XML.

### 🔹 UP2 · Acceso a Bases de Datos Relacionales

Conexión a bases de datos relacionales desde Python con Connector/Python: operaciones CRUD, transacciones, y procedimientos y funciones almacenadas.

### 🔹 UP3 · Spring Boot. Modelo Cliente - Servidor

Introducción a Spring y Spring Boot, el patrón **MVC**, creación de controladores REST y recepción de parámetros (consulta, ruta y cuerpo de la petición).

### 🔹 UP4 · Modelo de datos. Entidades

SGBD con Docker, el desfase objeto-relacional y JDBC, y mapeo de entidades con **Hibernate / JPA**: anotaciones, ciclo de vida de las entidades e importación de datos.

### 🔹 UP5 · Modelo de datos. Relaciones

Relaciones entre entidades con Hibernate/JPA: relaciones 1 a 1, 1 a N, N a M y N a M con atributos, carga de datos (*lazy* / *eager*) y propagación en cascada.

### 🔹 UP6 · Creación de una API REST con Spring Boot

Diseño y construcción de una API REST completa: arquitectura en capas (Controller / Service / Repository), Spring Data JPA, DTOs, validación de datos, manejo global de errores y exposición de relaciones, con una guía práctica paso a paso usando **IntelliJ IDEA**.

### 🔹 Prácticas

Cada unidad incluye sus propias prácticas, enlazadas justo después del bloque de teoría al que corresponden.
